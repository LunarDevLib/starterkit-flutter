# starterkit_qr_barcode

Optional, default-disabled still-image QR/barcode decoding for Flutter Starter
Kit. See the repository's [capability contract](../../docs/capabilities/QR_BARCODE.md)
for bounds, platform behavior, activation, and verification status.

The standalone package supports Flutter 3.47+ and Dart 3.13+. It does not provide
camera, picker, path, URL, permission, or navigation behavior.
